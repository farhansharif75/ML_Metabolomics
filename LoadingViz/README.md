# Data Loading & Visualisation
This folder contains the preliminary analysis performed on the .h5 and .csv files collected by Lia and used as part of our project.
This includes data loading and visualisation along with the computational framework used to cleanly load and save the data used in downstream analysis.
The main methodology is described and detailed in the notebook: `LoadingViz.ipynb` and the main results of interest are included in the other subfolders.
